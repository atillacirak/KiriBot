KiriBot Privacy Policy

Last Updated: September 6, 2026 • Yeşil Gölet Discord Ecosystem

1. Overview

KiriBot is a dedicated community management and engagement bot built for the Yeşil Gölet Discord server. This policy outlines how user data is collected, stored, and protected.

2. Data We Collect

  • Discord User Information: User ID, Username, Display Name, and Avatar URL to display on the leaderboard and manage user levels.
  • Activity Metrics: Voice channel activity duration and message count/XP points solely used for calculating user levels and rank progression.
  • Server Analytics: Aggregated member join/leave counts and channel message volume for server growth statistics.

3. What We Do NOT Collect

We do not store passwords, credit card details, or personal real-world identities. Message content is processed in real-time solely for XP calculation purposes. Direct messages sent to the bot are stored in the admin inbox for community management and can be deleted upon request.

4. Data Storage & Security

All data is securely hosted on an enterprise-grade MongoDB Atlas cloud database with SSL/TLS encryption in transit and AES-256 encryption at rest. Data is retained as long as necessary for the bot's functionality (e.g. XP leaderboard). We never sell, rent, or share any user data with third parties.

5. Data Deletion & Contact

You have the right to request deletion of all data associated with your Discord account at any time. Upon a verified request, we will permanently remove your XP records, join/leave history, and any stored messages from both our cloud database and local backups within 30 days.

📩 How to Request Data Deletion

1

Discord — Direct Message the Bot

Send a DM to KiriBot on Discord requesting data deletion. Include your Discord User ID in the message.

2

Discord — Server Admin Contact

Open a ticket or contact an admin in the Yeşil Gölet Discord server and request data deletion with your Discord User ID.

3

Privacy Policy Page

This page is publicly accessible at https://yesilgolet.duckdns.org/privacy and linked in the bot's Discord profile.

Please include your Discord User ID in your request so we can locate and delete the correct records. Requests are processed within 30 days.
